# DayFlow v3

DayFlow ist eine statische, GitHub-Pages-fertige Tagesplaner-App. Beim ersten Start kommt direkt das Profil-Onboarding. Nach dem Speichern wird automatisch ein persönlicher Tagesplan erzeugt, lokal gespeichert und die App öffnet **Heute**.

## Enthalten

- Automatisches Onboarding mit Name, Alter, Gewicht, Größe, Schlaf, Aufsteh-/Schlafzeit, Aktivität, Ziel und Arbeits-/Schulzeit
- Automatische Tagesplanung mit Frühstück, Fokus-/Lernblöcken, Pausen, Mittagessen, Bewegung, Freizeit, Abendessen und Abendroutine
- Plan automatisch lokal gespeichert und für weitere Tage erzeugbar
- Plan neu erstellen, einzelne Aufgaben hinzufügen, erledigen, löschen und in 15-Minuten-Schritten verschieben
- Top-3-Aufgaben und Tagesfortschritt
- Kalender mit Monatsansicht und Tagesauswahl
- Gewohnheiten mit 7-Tage-Tracker und Streaks
- Notizen, Essensplan, Einkaufsliste, Brain Dump, Wochenreview, Dankbarkeit und Projekt-Milestone
- Fokusmodus / Timer
- Tages-Check-in mit Stimmung und Verlauf
- 7-Tage-Statistik und Erfolgsquote
- Wetter laden über Open-Meteo direkt aus dem Browser (Standortfreigabe optional)
- Browser-Benachrichtigungen anfordern
- Tagesplan teilen über Web Share / Zwischenablage
- JSON-Export und -Import
- einfacher ICS-Kalenderimport
- Dark Mode
- PWA / Offline-Caching und Installationsmöglichkeit
- Daten bleiben standardmäßig im Browser; kein Backend erforderlich

## Profil & Empfehlungen

Alter und Gewicht können eingetragen werden. DayFlow nutzt diese Angaben nicht für medizinische Diagnosen, gefährliche Kalorienvorgaben oder aggressive Abnehmziele. Stattdessen werden allgemeine Routinen zu Schlaf, Bewegung, Essen, Pausen, Fokus und Wohlbefinden empfohlen. Für Minderjährige liegt der Fokus ausdrücklich auf Wohlbefinden und Routinen statt Gewicht.

## GitHub Pages

1. Neues GitHub-Repository erstellen.
2. Alle Dateien aus diesem Ordner ins Repository laden.
3. Unter **Settings → Pages** `Deploy from a branch`, Branch `main` und Root `/` auswählen.
4. Die GitHub-Pages-Adresse öffnen.

Keine Installation und kein Server sind nötig.
