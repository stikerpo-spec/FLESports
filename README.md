# DayFlow v2

Eine moderne, komplett statische Tagesplaner-Web-App für GitHub Pages.

## Neu in Version 2

- Persönliches Profil mit Name, Alter, Gewicht, Größe und Schlafdauer
- Aktivitätslevel und persönliches Tagesziel
- Automatisch generierte Lifestyle-Vorschläge passend zu deinem Profil
- Vorschläge für Bewegung, Schlaf, Fokus, Pausen und Tagesstruktur
- BMI kann für Erwachsene nur als grobe Orientierung angezeigt werden
- Für Minderjährige werden keine gewichtsbasierten Ziele vorgeschlagen
- Profil bleibt lokal im Browser gespeichert

## Enthalten

- Tagesablauf mit Uhrzeiten und Aufgaben
- Aufgaben abhaken, priorisieren und Top-3 markieren
- Gewohnheiten mit 7-Tage-Tracker und Streaks
- Notizen und schnelle Ideen-Listen
- Pomodoro/Focus-Modus mit 15 / 25 / 50 Minuten
- Tagesfortschritt und 7-Tage-Statistik
- Dark Mode
- Export / Import als JSON-Backup
- Speicherung via `localStorage`
- Kein Backend erforderlich

## GitHub Pages

1. Repository anlegen und `index.html`, `style.css`, `app.js`, `README.md` hochladen.
2. In GitHub unter **Settings → Pages** die Quelle `main` und das Root-Verzeichnis auswählen.
3. Nach dem Deploy ist DayFlow über deine GitHub-Pages-Adresse erreichbar.
